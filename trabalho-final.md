# Trabalho Prático Individual — Organizaê

**Tema:** Desenvolvimento de uma aplicação web interativa com HTML, CSS e JavaScript.

> **Data de entrega:** 19/11/2026 

## Objetivo

Construir uma aplicação de gerenciamento de tarefas que funcione diretamente no navegador, aplicando os conhecimentos de estruturação de páginas, estilização e programação com JavaScript e **HOSPEDÁ-LO NO GITHUB PAGES**

## O que desenvolver

A aplicação deverá permitir cadastrar, listar, editar, concluir e excluir tarefas. Também deverá oferecer filtros por status, contadores de tarefas e persistência dos dados no navegador usando `localStorage`.

A interface deverá ser organizada, responsiva e apresentar feedback adequado às ações do usuário.

## Tecnologias obrigatórias

- HTML5
- CSS3
- JavaScript puro
- Git e GitHub

> Não é permitido utilizar frameworks frontend para implementar a aplicação. (nem bootstrap)

## Entrega

O projeto deverá ser disponibilizado em um repositório público no GitHub, contendo os arquivos-fonte organizados, um README com a documentação básica e o link para a aplicação publicada no GitHub Pages.

O histórico do repositório deverá demonstrar a evolução do desenvolvimento por meio de commits significativos.

## Avaliação

Serão avaliados a semântica HTML, a organização do CSS, a lógica JavaScript, o funcionamento das funcionalidades, a responsividade, a persistência dos dados e a documentação do projeto.

O estudante deverá ser capaz de explicar as principais partes do código e realizar uma pequena alteração durante a avaliação.

**Importante:** a entrega não será avaliada apenas pela aparência. O funcionamento, a qualidade da implementação e a compreensão individual do código também fazem parte da nota.
